# C Programming Exercises - Arrays and Strings

This folder contains beginner-friendly C exercises for learning arrays and strings.

## Files

1. **[arrays_exercises.c](arrays_exercises.c)** - 5 exercises about arrays
2. **[strings_exercises.c](strings_exercises.c)** - 5 exercises about strings

## How to Compile and Run

### On Windows (using GCC/MinGW):
```bash
gcc arrays_exercises.c -o arrays.exe
arrays.exe

gcc strings_exercises.c -o strings.exe
strings.exe
```

### On Linux/Mac:
```bash
gcc arrays_exercises.c -o arrays
./arrays

gcc strings_exercises.c -o strings
./strings
```

## Array Exercises

1. **Print Array Elements** - Learn to loop through and display array values
2. **Sum of Array Elements** - Calculate the total of all numbers in an array
3. **Find Largest Element** - Find the maximum value in an array
4. **Reverse an Array** - Reverse the order of elements
5. **Copy Array** - Copy elements from one array to another

## String Exercises

1. **String Length** - Count characters in a string manually and using strlen()
2. **Copy String** - Copy one string to another character by character
3. **Compare Strings** - Check if two strings are equal
4. **Concatenate Strings** - Join two strings together
5. **Reverse a String** - Reverse the characters in a string

## Learning Tips

- Each exercise is in its own function for clarity
- Comments explain what each section does
- Start with arrays_exercises.c, then move to strings_exercises.c
- Try modifying the values and see what happens!
- Experiment by creating your own variations

## What You'll Learn

### Arrays:
- How to declare and initialize arrays
- Accessing array elements using indices
- Looping through arrays
- Array manipulation (reversing, copying)

### Strings:
- Understanding strings as character arrays
- The null terminator '\0'
- String manipulation functions
- Character-by-character operations

Good luck with your learning!
